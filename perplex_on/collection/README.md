# PERPLEX ON Collection

Three panels by PERPLEX ON, together in one firmware download:

- **Pendulum** — a pendulum-driven sequencer. [PDF manual](../pendulum/manual.pdf)
- **Kristallwuchs** — a crystal-growth sequencer. [PDF manual](../kristallwuchs/manual.pdf)
- **Spiegel 12** — a four-voice instrument inspired by Laurie Spiegel's Music Mouse. [PDF manual](../spiegel_12/manual.pdf)

Flash the collection once, then choose a panel on your Plinky. Grid is included alongside the three panels. The panels run individually, not simultaneously.

**Open in IDE** loads all three source files and Grid into separate tabs so you can customise the collection. Existing edited tabs are preserved; if there isn't enough space, close some panel tabs first.
